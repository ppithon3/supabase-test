# Supabase Test

Mini-projet pour tester Supabase avec un formulaire HTML simple.

## Fonctionnalités
- formulaire avec 2 champs : `Titre` et `Description`
- stockage des données dans une table Supabase
- affichage en liste des entrées enregistrées

## Configuration Supabase
1. Crée un projet sur Supabase.
2. Dans `Settings > API`, copie `Project URL` et la clé publishable (`sb_publishable_...`).
3. Remplace `SUPABASE_ANON_KEY` dans `script.js` par ta clé publishable.

## Déployer avec GitHub + Supabase Pages
1. Mets le projet dans un dépôt GitHub avec au minimum : `index.html`, `style.css`, `script.js`, `README.md`.
2. Dans le dashboard Supabase, va dans `Pages` et clique sur `New Site`.
3. Connecte ton dépôt GitHub et choisis la branche (`main` ou autre).
4. Configure :
   - `Build command` : laisse vide ou `echo "no build"`
   - `Publish directory` : `/`
5. Clique sur `Deploy`.
6. Attends la publication et ouvre l’URL fournie par Supabase.

Si tu veux un déploiement vraiment simple : tu peux utiliser ton dépôt GitHub existant et publier la racine du projet.

## Table à créer
Utilise ce SQL dans `SQL Editor` de Supabase :

```sql
create table if not exists entries (
  id bigint generated by default as identity primary key,
  title text not null,
  description text not null,
  created_at timestamp with time zone default timezone('utc', now())
);
```

## Lancer le projet
- Ouvre `index.html` dans un navigateur
- Ou lance un serveur local simple, par exemple :
  - `npx http-server .` (si Node est installé)
  - `python -m http.server 5500`
